# STUDIA — Cloudflare Workers + D1

ეს პროექტი Supabase-ს არ იყენებს. რეგისტრაციის მოთხოვნები ინახება Cloudflare D1 მონაცემთა ბაზაში. სტუდენტი ირჩევს პაროლს, ადმინი კი თავის დაცულ გვერდზე ამტკიცებს/უარყოფს ანგარიშს.

## რა არის საჭირო
- უფასო Cloudflare ანგარიში
- არსებული GitHub Pages რეპოზიტორია
- ადმინის ძლიერი პაროლი

**შენიშვნა:** მე ვერ შევდივარ შენს Cloudflare/GitHub ანგარიშებში და ვერ ვასრულებ შენს ნაცვლად ანგარიშის შექმნას ან გამოქვეყნებას. ქვემოთ მოცემული ნაბიჯებით უნდა დააკავშირო სერვისი.

## ნაწილი 1 — შექმენი D1 ბაზა
1. შედი https://dash.cloudflare.com/
2. მარცხნივ გახსენი **Workers & Pages** → **D1 SQL Database** (ზოგ UI-ში D1 ცალკე ჩანს).
3. დააჭირე **Create database** და დაარქვი `studia-db`.
4. ბაზის შექმნის შემდეგ გახსენი მისი **Console**.
5. გახსენი `worker/schema.sql`, მთლიანად დააკოპირე SQL და გაუშვი D1 Console-ში.
6. ბაზის გვერდზე მოძებნე Database ID და დააკოპირე.

## ნაწილი 2 — შექმენი Worker API
1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Worker**.
2. დაარქვი `studia-api` და Deploy.
3. გახსენი Worker → **Edit code**. ჩაანაცვლე კოდი `worker/index.js` ფაილის სრული შიგთავსით და Deploy.
4. Worker-ის **Settings → Bindings**-ში დაამატე **D1 Database** binding:
   - Variable name: `DB`
   - Database: `studia-db`
   - Save/Deploy.
5. Worker-ის **Settings → Variables and Secrets**-ში დაამატე Secret:
   - Name: `ADMIN_PASSWORD`
   - Value: ძლიერი, უნიკალური პაროლი (მინიმუმ 16 სიმბოლო).
   შეინახე ცვლილება/Deploy. ეს პაროლი `admin.html`-ში არ იწერება.
6. Worker-ის URL ჩვეულებრივ ჰგავს `https://studia-api.<შენი-ქლაუდფლეარის-subdomain>.workers.dev`. გახსენი URL + `/api/health`; პასუხში უნდა გამოჩნდეს `{"ok":true}`.
7. თუ Worker-ის კოდს Dashboard-ში არედაქტირებ, `worker/wrangler.toml` აუცილებელი არ არის. თუ Wrangler-ით deploy-ს იყენებ, `database_id` ველი შენი რეალური Database ID-ით შეცვალე და `ADMIN_PASSWORD` secret-ად დააყენე.

## ნაწილი 3 — GitHub Pages-ის დაკავშირება
1. გახსენი GitHub რეპოზიტორია: https://github.com/mrbladepipo7-a11y/TSU-UNI-SHUA/
2. ატვირთე/ჩაანაცვლე ამ ZIP-ის ძირეულ საქაღალდეში არსებული `index.html`, `admin.html`, `style.css`, `app.js`, `admin.js`, `config.js`. `worker` საქაღალდე შეგიძლია რეპოში შეინახო, მაგრამ მისი კოდი საჯაროა; აქ საიდუმლო არ არის.
3. გახსენი `config.js` და ჩაანაცვლე `https://YOUR-WORKER-NAME.YOUR-SUBDOMAIN.workers.dev` შენი რეალური Worker URL-ით.
4. Commit changes. რამდენიმე წუთში GitHub Pages-ზე განახლდება.
5. რეგისტრაცია გამოსცადე სხვა ელფოსტით. შემდეგ `admin.html`-ზე შედი ადმინის პაროლით და მოთხოვნა დაამტკიცე.
6. დამტკიცების შემდეგ სტუდენტი მთავარ გვერდზე შეიყვანს თავის ელფოსტასა და არჩეულ პაროლს.

## მასალების დამატება
ამ ვერსიაში ადმინ-გვერდზე ემატება **სათაური + საჯარო URL + აღწერა**. ფაილი პირდაპირ არ იტვირთება. PDF-ის/ფაილის ბმული შეგიძლია განათავსო GitHub-ში ან ისეთ ფაილურ სერვისში, სადაც სტუდენტებს ნახვის უფლება ექნებათ, და შემდეგ ჩასვა ბმული. თუ გინდა ფაილების პირდაპირ ატვირთვა, საჭიროა ცალკე Cloudflare R2 დაყენება.

## მნიშვნელოვანი უსაფრთხოების შენიშვნები
- ეს ვერსია არ აგზავნის ელფოსტას და არ მოითხოვს ელფოსტით დადასტურებას. ამიტომ რეგისტრაციის მოთხოვნის გაგზავნა მხოლოდ იმას ამტკიცებს, რომ ვიღაცამ ეს მისამართი შეიყვანა; ელფოსტის მფლობელობას არ ამოწმებს.
- Worker-ის API-ის მისამართი საჯაროა, რაც ნორმალურია. ადმინის მოქმედებები დაცულია `ADMIN_PASSWORD`-ით.
- სტუდენტის პაროლი ჰეშდება PBKDF2-ით და ბაზაში ტექსტურად არ ინახება.
- Cloudflare Free нь хязгааргүй биш: Workers-ийн өдөрт 100,000 хүсэлт, D1-ийн өдөр тутмын унших/бичих мөрийн квოტ бий. 180 სტუდენტის жижиг საიტისთვის ჩვეულებრივ საკმარისი უნდა იყოს, მაგრამ გარანტირებული შეუზღუდავი სერვისი არ არის.
- ეს არის საწყისი ვერსია. საჯაროდ გაშვებამდე შეამოწმე რეგისტრაცია, ადმინის შესვლა, დამტკიცება და სტუდენტის შესვლა.
